# 公路車百科 32 部位校核

校核日期：2026-09-14

## 校核方式

- 以 `js/ui/bike-anatomy.js` 的實際 SVG 幾何為準，逐一確認每個熱點位於該部位的著色範圍，而不是只比對資料與元件內重複宣告的座標。
- 另檢查車架管件的連接拓樸：下管必須從頭管下端 `(632, 250)` 接至中軸區 `(455, 350)`，不可與上管一起誤接頭管上端。
- 飛輪與後軸、碟盤與前花鼓等同心零件採邊緣熱點，以避免互動熱點完全重疊；這些點仍落在對應零件的實際筆畫上。
- 內容以 Shimano 技術文件與 Park Tool 維修資料交叉校核。這是一般性百科，不取代特定車款製造商的規格與維修手冊。

## 內容校核結論

- 煞車卡鉗：改為分別說明油壓碟煞、機械碟煞與輪圈煞車。只有油壓系統涉及油管、漏油檢查與排氣；機械碟煞以拉線、作動臂與來令片間隙調整。Shimano 的油壓碟煞手冊以煞車油管與排氣程序為核心，機械碟煞 BR-R317 手冊則明列拉線調整器與來令片調整螺絲。
- 摩擦片：明確區分碟煞「來令片」與輪圈煞車「煞車皮」，並限定輪圈煞車皮只能作用於輪圈煞車面。
- 輻條：改為追求同一側的相對張力均勻；後輪飛輪側與碟煞前輪碟盤側因花鼓法蘭偏置，左右側張力可不同，不應強求相等。
